## 1. 핵심 결론 (Executive Summary)

1. **최종 실전 후보 확정 — `A-FR` (A-0 + 외인·기관 확정 수급 + 시장 레짐 필터 & 회전율 완화)**
   - 왕복 거래비용 **0.73%**를 차감한 순수익(Net) 기준으로, **전 구간(2021.01~2026.11) CAGR +26.09% (총수익률 +275.82%, 1억 → 3.76억), 샤프 0.96, MDD -41.69%**를 달성했습니다.
   - **OOS(2024.07~2026.11)**에서는 **CAGR +47.49% (총수익률 +144.94%), 샤프 1.48, MDD -21.32%**를 기록하며 KOSPI 단순보유(OOS CAGR +30.03%, 샤프 0.85, MDD -45.49%)를 **수익률·샤프·MDD 3관왕으로 완벽 압도**했습니다.
   - **7개 비교 모델 중 유일하게 Z3-Solver SLA-1 ~ SLA-8(구조 무결성 + OOS 양수 + Full & OOS 전 구간 KOSPI 3관왕 우월성) 전 항목 `SAT`를 통과**했습니다.
2. **남겨야 할 필터 vs 과감히 버려야 할 필터 (Ablation Study 판정)**
   - **[채택 — 최강 기여] 시장 레짐 필터(지수 > MA60 & 5일 급락 없음) + 회전율 완화(MA20 이탈, 트레일링 -15%)**:
     - `A-0 → A-R` 적용만으로 Full CAGR **+8.37% → +19.81% (+11.44%p)**, Full MDD **-62.10% → -43.51% (+18.59%p 방어)**, IS CAGR **-3.09% → +14.02%** 흑자 전환, 매매횟수 절반 축소(830회 → 419회).
   - **[채택 — 알파 증폭] 실제 KRX 외인·기관 확정 수급 필터(당일 거래대금 대비 >= +2% & 3일 누적 > 0%)**:
     - `A-R → A-FR` 결합 시 Full CAGR **+19.81% → +26.09% (+6.28%p)**, 샤프 **0.74 → 0.96**, OOS CAGR **+27.90% → +47.49% (+19.59%p)**, OOS MDD **-26.31% → -21.32%**. 개인 추격 설거지 급등을 효과적으로 제거함.
   - **[폐기 — 수익 파괴] '거래대금 Top30 신규 진입' 필터 (직전 20일 Top30 빈도 <= 5회 & RS > 지수)**:
     - `A-1 → A-2` 적용 시 Full CAGR **+12.26% → -5.03% (-17.29%p 붕괴)**, `A-R → A-LR` 적용 시 **+19.81% → -2.96% (-22.77%p 붕괴)**, `A-FR → A-3` 적용 시 **+26.09% → +8.16% (-17.93%p 붕괴)**.
     - **원인**: 이미 거래대금 상위 30위권에 꾸준히 안착해 대세 랠리를 이어가는 **진짜 대형 주도주(반도체·방산·조선·전력기기·바이오 대장주)**를 "기존 Top30 빈도 초과"로 모조리 탈락시키고, 단발성 2등주/테마주만 남겼기 때문입니다. 데이터에 따라 과감히 폐기합니다.

|---|---|
| **수급 데이터 출처** | Naver Finance 종목별 투자자 매매동향 API (`m.stock.naver.com/api/stock/{code}/trend`) → `krx_surge_data.duckdb`의 `investor_flow` 테이블에 영구 캐싱 |
| **수집 범위 및 커버리지** | 기존 200종목(KOSPI 100 + KOSDAQ 100) 중 **200/200종목 수집 성공 (실패 0건)**, **311,013 rows**, 백테스트 구간(`2021-01-04 ~ 2026-11-19`) 행 커버리지 **98.85%** (결측일은 억지 보간 없이 `NaN` 유지) |
| **수급 지표 정의** | 당일 순매수 비율 = `(외국인 순매수수량 + 기관 순매수수량) / 당일 비수정 거래량` (액면분할/수정주가 왜곡 0%), 3일 누적 순매수 비율 = `3일 누적 외인+기관 순매수금액 / 3일 누적 거래대금` |
| **Zero Look-Ahead** | `t`일 장 마감 후 확정된 OHLCV·수급·거래대금 순위·지수 레짐으로 신호 생성 → **`t+1`일 시가 진입** 엄수 |

## 5. 한계점 고지 및 다음 단계 권고

1. **생존 편향(Survivorship Bias) 고지**: 기존 200종목 유니버스는 2026년 11월 현재 상장 및 시총 상위 보통주 기준이므로, 2021~2026년 사이 상장폐지되거나 시총이 급락해 탈락한 종목이 제외된 생존 편향이 일부 존재합니다. (`A-FR`의 실제 수익률은 보수적으로 연 3~5%p 할인해 해석하는 것이 합리적이며, 이를 할인하더라도 KOSPI +10.24% 대비 압도적 우위 유지).
2. **다음 단계 권고**:
   - **독립 감사관(`quant-auditor`) 교차 감사**: `A-FR` 전략의 코드 재실행, 체결 내역 CSV 검증 및 Z3 SLA 교차 확인 후 **KRX 단기/중기 Bucket 1호 정식 전략**으로 확정.
